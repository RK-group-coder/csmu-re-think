# 大慶拾物所｜中山醫學大學校園二手交換與漂書平台 (re-think-csmu)

專為**中山醫學大學 (CSMU)** 學生與教職員打造的校園無金流二手教材、宿舍家電、好市多團購拆售與公益漂書交換平台。

## 專案啟動方式

```bash
npm install
npm run dev
```

## 核心功能與結構對應

### 一、功能總覽
- **首頁**：
  - **頂部搜尋列與熱門關鍵字**：支援書名、ISBN、科目即時檢索，點擊熱門關鍵字（`Netter解剖學圖譜`、`OSCE聽診器`、`實驗衣`、`iPad類紙膜`、`大慶退宿小冰箱`、`一點絕`、`好市多貝果拆售`、`免費漂書`）直接篩選。
  - **輪播公告欄**：包含「校園活動（正心樓二手市集）」、「公益二手書募集（教務處 3C 物資＆圖書館漂書）」、「平台防詐提醒」，支援後台即時新增全站廣播。
  - **熱門分類快捷入口**、**急售 / 降價專區**、**最新上架商品區**。
- **分類瀏覽頁**：
  - **多重篩選器**：分類與學院科系子分類、價格區間、新舊程度、中山醫交易地點（正心樓一樓郵局前、誠愛樓大廳、張啟華圖書館、杏樓、大慶捷運站、附設醫院汝川大樓、實驗大樓）。
  - **排序功能**：最新上架、價格低至高、價格高至低、最多人關注。
- **商品卡與商品詳細視窗**：
  - 多圖切換（標示首圖封面）、詳細規格（預售價、原價比對、是否可議價、新舊程度、有效期限、數量、面交方式）。
  - **賣家資訊卡**：頭貼、系級、交易誠信徽章、歷史評價星級與評語、一鍵站內私訊、賣家其他在售商品。
  - **公開問與答 / 留言板**：買家公開提問、賣家即時回覆。
- **個人資訊（右上角頭貼選單）**：
  - 我的管理（上架中、保留中、已售出、已下架、追蹤收藏清單）、私訊訊息匣、關鍵字訂閱與信箱通知匣、個人設定與 Google 驗證狀態、公開個人頁面預覽。

### 二、帳號與權限管理
- **Google 帳號驗證**：支援 CSMU Google Workspace (`@csmu.edu.tw`) 驗證。
- **買家與賣家權限分級**、**個人誠信徽章**與 **1~5 星歷史評價（或顯示「未評分」）**。

### 三、商品與分類管理
- **商品上架**：支援上傳最多 8 張圖片、滑鼠拖曳排序 (Drag & Drop)、首圖設定。
- **特殊效期欄位檢核**：食品與彩妝/保養品強制填寫有效日期；**過期商品自動攔截禁止上架**，30 天內即期品自動顯示 **「⚠️ 即期警示標籤」**。
- **結構化分類**：教科書（依醫學院、醫學科技學院、健康管理學院、醫學人文暨社會學院、通識分類，含科目與版次）、通用書籍（含免費漂書專區）、3C/家電、日常用品、娛樂、食品、公益物資、**求購專區**。

### 四、交易管理（無金流）
- **站內私訊**：頂部自動帶入相談商品圖片與價格、內建預設常用語句、支援傳送商品細節圖片。
- **交易狀態切換**：`上架中`、`保留中`（暫停其他人私訊）、`已售出`（選擇買家並觸發雙方互評）、`已下架`。
- **評價與守時爭議回報**：1~5 星互評與評語，以及「放鳥 / 未到」、「描述不符」爭議檢舉。

### 五、安全、檢舉與系統營運
- **安全防詐提醒**：全站防詐標語，私訊傳送外部 URL 自動跳出紅框安全攔截提醒。
- **一鍵檢舉與後台管理系統**：支援檢舉黃牛票券、違禁品、假貨、過期食品、放鳥詐騙；後台提供**違規商品強制下架**、**帳號停權 / 警告機制**與**全站廣播公告發布**。

### 六、其他特色功能
- **教科書 ISBN 條碼掃描**：啟動相機條碼掃描器，一鍵掃描自動帶入書名、作者、版次、科目與原價。
- **關鍵字訂閱**：設定熱門科目或物品關鍵字，有賣家上架自動觸發通知並模擬寄信至註冊信箱 (`@csmu.edu.tw`)。
